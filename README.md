# مَشهد — محرر فيديو عربي

تطبيق ويب (PWA) لمونتاج الفيديو يعمل بالكامل داخل المتصفح، بواجهة عربية واتجاه RTL، وتصميم داكن مناسب للجوال.

**الاسم:** مَشهد  
**صاحب الحقوق:** وطن النهار © 2026 — جميع الحقوق محفوظة  
**الترخيص:** ملكية خاصة — لا يُنسخ ولا يُعاد نشره دون إذن

## الفكرة

مستوحى من *مجموعة ميزات* تطبيقات المونتاج الشائعة (استيراد، خط زمني، نص، فلاتر، تصدير)، لكن الاسم والشعار والتصميم والكود أصليان بالكامل. لا يستخدم أي أصول أو علامات تجارية من CapCut أو غيره.

## الميزات

- استيراد فيديو / صورة / صوت
- خط زمني متعدد المسارات (فيديو، نص/ملصقات، صوت)
- قصّ، تقسيم، نسخ، إعادة ترتيب، حذف
- معاينة على Canvas
- نصوص عربية (خط Cairo) مع لون وحجم وحركة
- ملصقات وإيموجي
- فلاتر (سطوع / تباين / تشبّع + إعدادات جاهزة)
- تغيير سرعة المقطع
- انتقالات (تلاشي / انزلاق)
- موسيقى خلفية ومستوى الصوت
- مقاسات 9:16 و 16:9 و 1:1
- تصدير WebM عبر MediaRecorder (وMP4 إن دعمه المتصفح)
- تراجع / إعادة
- حفظ المشروع في IndexedDB
- يعمل كتطبيق مثبت (PWA) ويعمل جزئياً دون إنترنت بعد الزيارة الأولى

## التشغيل محلياً

```bash
cd mashhad
python3 -m http.server 8765
# ثم افتح http://127.0.0.1:8765
```

## القيود المعروفة

- التصدير يعتمد على MediaRecorder؛ معظم المتصفحات تنتج WebM وليس MP4
- مزج الصوت أثناء التصدير قد يفشل في بعض المتصفحات بسبب قيود Web Audio
- لا يوجد تأثيرات سينمائية متقدمة ولا مفاتيح لونية معقّدة في هذه النسخة
- الأداء على المقاطع الطويلة جداً يعتمد على قوة الجهاز
- المشروع يُحفظ في متصفح الجهاز فقط؛ مسح بيانات الموقع يحذفه
